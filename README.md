# ยังไม่เสร็จ — ทะเบียนตึกร้างของหน่วยงานรัฐ

Single page รวมอาคารของส่วนราชการ องค์กรอิสระ ท้องถิ่น และสถานศึกษา
ที่สร้างไม่เสร็จ / สร้างเสร็จแต่ไม่เปิดใช้ / ถูกทิ้งร้าง

ที่มา: [โพสต์ของ Nat Luengnaruemitchai](https://www.facebook.com/nat.lueng/posts/pfbid02YWA9HKrk2BxemqbyE8zziNVjqbJLFB3sfNvPcRYRQHXcVTen4G7wxsksaQj2uBbel)
(17 ก.ย. 2569) ที่ขอรูปและพิกัดตึกราชการที่ร้างหรือสร้างไม่เสร็จ
ข้อมูลตั้งต้น 55 รายการมาจากคอมเมนต์ในโพสต์นั้น

## สถานะข้อมูล

- **55 รายการ · 29 จังหวัด · งบรวม ~22,362 ล้านบาท**
- **ยังไม่มีรายการไหนมีพิกัด** — `lat`/`lng` เป็น `null` ทั้งหมด แผนที่จึงแสดงเป็น
  วงกลมจำนวนรายการต่อจังหวัด วางที่จุดกลางจังหวัด ไม่ใช่ตำแหน่งอาคาร
- **ยังไม่ได้ตรวจสอบกับเอกสารราชการ** ทุกแถวเป็น `verified: false`
- 2 รายการไม่ระบุจังหวัด (สถานีตำรวจทดแทน 396 แห่ง และอาคารกรมควบคุมโรค)
  จะไม่ขึ้นบนแผนที่ แต่ยังอยู่ในไดเรกทอรี

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ทั้งหน้า — CSS, JS, แผนที่ Canvas, ไดเรกทอรี, เทมเพลตส่งข้อมูล |
| `buildings.js` | **ข้อมูลอาคาร** + จุดอ้างอิงจังหวัด + ตารางสถานะ/ประเภท — แก้ที่นี่ที่เดียว |
| `provinces.js` | เส้นขอบ 77 จังหวัด delta-encoded ไม่ต้องแก้ |

## เติมพิกัดให้รายการที่มีอยู่

แก้แถวนั้นใน `BUILDINGS` แล้วใส่สามค่านี้:

```js
lat: 13.84321, lng: 100.53765, precision: 'exact',
```

หน้าเว็บจะเปลี่ยนจากนับรวมในวงจังหวัด เป็นปักหมุดกากบาทตามสถานะให้อัตโนมัติ
และตัวเลข "ยังไม่มีพิกัด" บนแถบสถิติจะลดลงเอง

## เพิ่มรายการใหม่

คำอธิบายทุกฟิลด์อยู่ในคอมเมนต์หัว `buildings.js` เงื่อนไขที่ต้องระวัง:

- `province` ต้องสะกดตรงกับชื่อใน `provinces.js` ไม่ตรงจะขึ้น warning ใน console
  และถ้าจังหวัดนั้นยังไม่มีใน `PROVINCE_ANCHOR` วงกลมจะไม่ถูกวาด
- ปีทุกช่องเป็น **พ.ศ.** `budget` เป็นบาทเต็มจำนวน ไม่ใส่ comma
- `budgetApprox: true` เมื่อต้นทางใช้คำว่า "ราว" หรือ "กว่า" หน้าเว็บจะขึ้น `~` นำหน้า
- `note` เก็บคำจากต้นทางตามเดิม ไม่ต้องตีความเพิ่ม

## รูปภาพ

`photos` รับ URL ปกติได้เมื่อเปิดจากเครื่องหรือโฮสต์เอง แต่ถ้า deploy เป็น
Claude Artifact ตัว CSP จะบล็อกรูปจากโดเมนอื่น ให้ใช้ทางใดทางหนึ่ง:

1. อัปโหลดเข้า asset store ของ artifact แล้วใช้ URL ที่ได้คืนมา
2. ฝังเป็น data URI (`data:image/webp;base64,...`) — ขนาดหน้ารวมต้องไม่เกิน 16MB

เหตุผลเดียวกันทำให้หน้านี้ไม่ใช้ Leaflet/OpenStreetMap — tile โหลดไม่ได้
แผนที่จึงวาดจาก `provinces.js` ลง Canvas เอง

## รันดู

```
python3 -m http.server 8000
```

## ที่มาข้อมูลแผนที่

`provinces.js` สร้างจาก [apisit/thailand.json](https://github.com/apisit/thailand.json)
ลดจุดด้วย Douglas-Peucker (eps 0.01°) เหลือ 4,475 จุด เก็บเป็น delta ระดับ 1/1000 องศา
จุดใน `PROVINCE_ANCHOR` คือ centroid ของรูปหลายเหลี่ยมจังหวัด (ถ้า centroid ตกนอกเขต
จะเลือกจุดในเขตที่ห่างขอบมากที่สุดแทน)
